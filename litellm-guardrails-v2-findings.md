## 2. OSS vs Enterprise (as documented / coded at v1.106.0)

OSS (MIT): all guardrail modes; `litellm_content_filter`; `presidio`; `generic_guardrail_api`; CustomGuardrail / custom_code; `decision_model`; `llm_as_a_judge`; `tool_permission`; `mcp_security`; every partner integration (Bedrock, Azure prompt_shield / text_moderations, model_armor, lakera_v2, pangea, noma_v2, lasso, pillar, panw_prisma_airs, aim, openai_moderation, guardrails_ai etc.); guardrail load balancing; `run_in_parallel`; fail modes; per-request `guardrails: [...]`; global policy attachments; `/guardrails/*` and `/policies/resolve` APIs; complexity router with built-in heuristic, LLM and OSS classifiers.

Enterprise (licence): per-key guardrail control; tag-based guardrail modes; model-level guardrails; team lock on guardrail toggles; team/key policy attachments; dynamic `extra_body` guardrail params; secret detection (`hide-secrets`); team-based tag routing; tag budgets. Auto router customisation is metered by the `auto_router` licence feature: without it you get one router per gated capability (heuristic v2, custom scoring, custom tiers/instructions, Capability, Fuse v2). Docs label Auto Router "[Add-on]" and the complexity router config "[Beta]".

## 5. Galileo as one option
1. **Callback `galileo`** (native, OSS): traces after the call; zero in-path latency; cannot block.
2. **Galileo Protect** (`POST https://api.galileo.ai/v2/protect/invoke`, stages + rulesets, PASSTHROUGH/OVERRIDE actions): via a CustomGuardrail adapter (no native hook). Luna-2 metrics require Galileo Enterprise.
3. **Agent Control** (Apache-2.0 server, `POST /api/v1/evaluation`, stage pre/post): via a CustomGuardrail or generic-guardrail adapter at the gateway, so no agent code change; `@control()` later for in-agent tool steps. Vendor benchmark p50 36 ms / p99 61 ms (local, 1 control) is a vendor claim.
4. **Luna-2 as Agent Control evaluator** (`galileo.luna2`): needs `GALILEO_API_KEY` on the server.
Note: Agent Control docs publish local-dev default API keys; they were not used and must be changed before any shared deployment.
